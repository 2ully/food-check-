# صالح؟ — فحص صلاحية المنتجات الغذائية

صفحة إلكترونية تفاعلية تساعد المستهلك على معرفة صلاحية الأغذية وتقليل مخاطر تناول المنتجات الفاسدة بطريقة سهلة وسريعة.

## ماذا يفعل الموقع؟

1. **الإدخال بكاميرا الجوال**
   - **مسح الباركود**: يفتح الكاميرا ويقرأ الباركود، ثم يجلب من قاعدة Open Food Facts المفتوحة اسم المنتج والشركة وبلد المنشأ ومسببات الحساسية.
   - **تصوير التاريخ**: يلتقط صورة لتاريخ الإنتاج والانتهاء ويقرؤها آليًا (تقنية OCR)، ثم يضع كل تاريخ في مكانه.
2. **بيانات المنتج** التي يحللها الموقع:
   - تاريخ الإنتاج والانتهاء (ونوعه: «انتهاء الصلاحية» أو «يُفضّل استهلاكه قبل»)، وتاريخ فتح العبوة إن كانت مفتوحة.
   - مسببات الحساسية: حليب البقر ومنتجات الألبان، بيض الدجاج، الفول السوداني، المكسرات الشجرية (الجوز، البقان، اللوز)، الأسماك (القاروص، السمك المفلطح)، الأسماك القشرية والمحار (الروبيان، سرطان البحر، السلطعون)، القمح، فول الصويا، والسمسم.
   - ظروف التخزين: مناسبة، أو غير مؤكدة، أو غير مناسبة.
   - مصدر المنتج: الشركة المصنعة، بلد المنشأ، رقم التشغيلة، والباركود.
   - الفحص الظاهري: انتفاخ العلبة، العفن، الرائحة، تغير اللون، وغيرها.
3. **نتيجة الفحص**
   - ✅ **طازج وصالح للاستهلاك**
   - ⚠️ **صالح بشروط** (قريب الانتهاء، أو ظروف تخزينه غير مؤكدة)
   - ❌ **منتهي الصلاحية / ظهرت عليه علامات فساد / غير مناسب لك (حساسية)**

   مع عدد الأيام المتبقية، وشريط يوضح عمر المنتج من الإنتاج إلى الانتهاء، وشرح لكل ملاحظة.
4. **حساسيتي**: يحفظ المستخدم المواد التي لديه حساسية منها، فينبهه الموقع إذا احتوى المنتج عليها.
5. **سجل الفحوصات**: آخر 30 فحصًا محفوظة على الجهاز، مع البحث والتصفية حسب النتيجة.

## كيف يعمل التحليل؟

| البيانات | القاعدة |
|---|---|
| تاريخ الانتهاء | إذا مضى التاريخ فالمنتج غير صالح. «يُفضّل استهلاكه قبل» في المنتجات الجافة يعطي تحذيرًا فقط لأنه يخص الجودة. |
| قرب الانتهاء | لكل نوع حدّ مختلف: يوم واحد للحوم والأسماك، يومان للألبان، 30 يومًا للمعلبات. |
| العبوة المفتوحة | لكل نوع مدة آمنة بعد الفتح (مثلًا 4 أيام للألبان، يوم واحد للأسماك). |
| ظروف التخزين | مناسبة = سليم، غير مؤكدة = تحذير، غير مناسبة = غير صالح. |
| الحساسية | إذا احتوى على مادة سجّلها المستخدم = «غير مناسب لك». |
| الباركود | يتحقق من رقم التحقق (آخر رقم)، ويحدد بلد تسجيل الباركود من أول 3 أرقام (GS1). |
| الفحص الظاهري | أي علامة فساد = غير صالح، والانتفاخ تحديدًا خطر التسمم الوشيقي. |

## الملفات

```
index.html   هيكل الصفحة
style.css    التصميم (يدعم الجوال والوضع الليلي)
app.js       الكاميرا + قراءة التواريخ + خوارزمية التحليل + السجل
```

المكتبات المستخدمة (تُحمّل من الإنترنت):
- [html5-qrcode](https://github.com/mebjas/html5-qrcode) لقراءة الباركود.
- [Tesseract.js](https://tesseract.projectnaptha.com/) لقراءة النص من الصور.
- [Open Food Facts API](https://world.openfoodfacts.org) قاعدة بيانات مجانية للمنتجات.

## التشغيل

**مهم:** الكاميرا المباشرة تعمل فقط عبر رابط آمن `https`. أسهل طريقة مجانية:

### GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub وارفع الملفات الثلاثة.
2. من **Settings → Pages** اختر الفرع `main` ثم **Save**.
3. بعد دقيقة يصبح الموقع على رابط مثل `https://username.github.io/food-freshness-checker/` ويمكن فتحه من الجوال.

### Netlify Drop (بدون حساب GitHub)
اسحب مجلد المشروع إلى https://app.netlify.com/drop فيعطيك رابطًا فورًا.

### على الكمبيوتر للتجربة
```
python3 -m http.server 8000
```
ثم افتح `http://localhost:8000`.

> إذا فُتح الموقع بدون https، يبقى زر «تصوير التاريخ» وخيار «التقاط صورة للباركود» يعملان لأنهما يستخدمان كاميرا الجوال عبر التقاط صورة.

## ملاحظة
الموقع أداة توعوية ولا يغني عن الفحص المخبري. عند الشك في سلامة أي منتج لا تتناوله.
